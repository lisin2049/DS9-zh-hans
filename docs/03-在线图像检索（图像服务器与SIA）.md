# 功能三：在线图像检索（内置图像服务器 + SIA）

> 一句话定位：**按天区从在线图像服务器抓图**（DSS 巡天、2MASS、SkyView 等），或用国际标准 **SIA（Simple Image Access）** 协议从注册表/指定服务器检索图像，直接显示在 DS9 里。
> 适用版本：SAOImageDS9 8.8（汉化版）。本文所有菜单位置均为**汉化后的中文界面**。

---

## 1. 这个功能是做什么的

DS9 内置了一批**在线图像服务器**，点几下就能按天区把巡天图像（光学 DSS、红外 2MASS、射电 NVSS/VLSS 等）拉回来显示，无需自己找下载链接。另外支持 **SIA 标准**：从 SIA 注册表里找图像服务，或直接使用已配置的 SIA 服务（如 HLA/STScI、SDSS）检索图像。

两条路径的区别：

| 方式 | 入口 | 特点 |
|---|---|---|
| **内置图像服务器** | 分析 → 图像服务器 | 固定的知名服务（DSS/2MASS/SkyView 等），即点即用 |
| **SIA 检索** | 分析 → 档案 → SIA | 标准协议，服务多、可自定义（偏好里可加服务） |

---

## 2. 方式 A：内置图像服务器（最简单）

### 界面入口

**路径：菜单栏 → 分析 → 图像服务器 →（选择服务）**

操作顺序：

1. 点击菜单栏 **分析**（Analysis）。
2. 悬停到 **图像服务器**（Image Servers）子菜单。
3. 选择你要用的服务器：

   - **DSS (ESO)** —— 欧洲南方天文台的数字化巡天（光学）
   - **DSS (STSCI)** —— 空间望远镜科学研究所的数字化巡天（光学）
   - **2MASS (NASA/IPAC)** —— 2 微米全天巡天（近红外）
   - **VLA (NRAO)** —— 甚大阵射电图像
   - **NVSS (NRAO)** —— NVSS 射电巡天
   - **VLSS (NRAO)** —— VLSS 低频射电巡天
   - **SkyView (NASA/HEASARC)** —— NASA SkyView 多波段检索入口

### 操作步骤

1. 选一个服务器（如 **DSS (STSCI)**）。
2. 在弹出的服务器对话框里填**天区**：天体名称（如 `M31`）或坐标。
3. （可选）设置图像尺寸、波段/文件类型等参数。
4. 点击 **检索/获取** 按钮 → DS9 联网向该服务器查询 → 返回的图像自动加载到新帧/当前帧。
5. 加载后可正常缩放、叠加坐标网格等。

> 这类对话框基本都包含：**目标（名称或坐标）**、**图像大小**、**是否新建帧** 等字段；DS9 会按当前帧中心预填。

## 3. 方式 B：SIA 图像检索（标准协议）

### 界面入口

**路径：菜单栏 → 分析 → 档案 → SIA →（选择服务或搜索注册表）**

操作顺序：

1. 点击菜单栏 **分析**（Analysis）。
2. 悬停到 **档案**（Archives）子菜单。
3. 悬停到 **SIA** 子菜单，看到两项：

   - **搜索 SIA 注册表**（Search SIA Registry）—— 从注册表检索可用图像服务
   - 分隔线以下的列表项 —— 已配置的 SIA 服务（默认包含 HLA/STScI、SDSS 等），**点某服务直接查询**

### 3.1 直接使用已配置服务（推荐）

在 **分析 → 档案 → SIA** 列表里点一个服务（如 SDSS），弹出该服务的 SIA 查询对话框：

1. 填**天区**（名称或坐标）。
2. 填**搜索半径**（或图像尺寸）。
3. （可选）填**波段/文件类型**参数。
4. 点 **检索** → DS9 按 SIA 协议向该服务发起查询 → 返回的图像/图像列表加载显示。

### 3.2 先搜索 SIA 注册表再选服务

1. 点击 **分析 → 档案 → SIA → 搜索 SIA 注册表**。
2. 在注册表检索对话框里填天区/关键词，点 **检索**。
3. 从返回的服务列表里选中一个 → **加载/应用**，即用该服务查询当前天区图像。

---

## 4. 配置项

**编辑 → 首选项 → SIA 面板**：

- 管理 SIA 服务列表：**添加/删除**服务（填服务标题、变量名、服务 URL、参数）。
- 修改默认服务参数。

内置图像服务器（DSS/2MASS/SkyView）固定集成在 **分析 → 图像服务器** 子菜单，一般无需配置。

**代理相关**：局域网受限时，在 **首选项 → HTTP** 配置 Web 代理，否则联网检索会失败。

---

## 5. 常见问题与提示

| 问题 | 处理办法 |
|---|---|
| 点服务器后一直"连接中" | 检查外网连通性；走代理则确认 **首选项 → HTTP** 配置正确 |
| DSS 返回空白/无数据 | 该天区在巡天覆盖之外，换波段/换服务器（ESO↔STSCI）试试 |
| 想要自定义 SIA 服务 | **首选项 → SIA** 面板添加服务 URL，再回 **分析 → 档案 → SIA** 使用 |
| 检索结果有多张图 | 通常会在新帧或帧栈里显示；用 **帧** 菜单切换查看 |
| 图像太大加载慢 | 调小请求的图像尺寸/搜索半径 |

---

*提示：内置图像服务器是"填天区→取图"的最快路径；SIA 适合需要特定服务（HLA、SDSS 等）或自定义服务的场景。*
