# 功能八：SAMP 协作（Simple Application Messaging Protocol）

> 一句话定位：让 DS9 与 **Aladin、TOPCAT** 等天文软件"互相对话"——互相发图像、发星表、同步坐标；联网主要体现在：对端工具（如 Aladin）常在线取数据，且图像以 URL 传递时需要双方都能访问该地址。
> 适用版本：SAOImageDS9 8.8（汉化版）。本文所有菜单位置均为**汉化后的中文界面**。

---

## 1. 这个功能是做什么的

SAMP 是虚拟天文台社区的标准消息协议。DS9 作为 SAMP 客户端，可以：

- **连接**到一个 SAMP hub（本机/局域网内其他工具共享的"消息总线"）。
- **发送**当前图像、当前星表给已连接的其他工具。
- **接收**其他工具发来的图像/星表/坐标，并自动加载显示。
- 接收"指向某天区"的消息，让 DS9 跳到指定坐标。

典型场景：

- DS9 里选中的源 → 发到 Aladin 查多波段图像。
- Aladin/TOPCAT 里选中的星表 → 发到 DS9 叠加显示。
- 两台机器/两个窗口联动同一目标。

> 联网说明：SAMP 消息本身走本机/局域网（TCP 连接 hub），**不一定要公网**；但很多对端工具（Aladin 等）在收到请求后是去**在线服务取数据**的，图像若以 URL 传递，接收方也需要能访问该 URL。

---

## 2. 界面入口（怎么从菜单调出来）

**路径：菜单栏 → 文件 → SAMP**

操作顺序：

1. 点击菜单栏 **文件**（File）。
2. 找到 **SAMP** 子菜单，包含：

   - **连接**（Connect）—— 连接当前 hub
   - **断开连接**（Disconnect）—— 断开
   - **图像 → 广播**（Image → Broadcast）—— 把当前帧图像发给所有已连接工具
   - **表 → 广播**（Table → Broadcast）—— 把当前星表/表格发给所有已连接工具

3. 旁边还有一个 **SAMP Hub** 子菜单：

   - **信息**（Information）—— 查看 hub 状态
   - **启动**（Start）—— 如果本机还没有 hub，DS9 可自己启动一个
   - **停止**（Stop）—— 停止本机 hub

> 另：文件按钮栏（工具栏）里也有 SAMP 的连接/断开/发送图像/发送表 快捷按钮。

## 3. 详细操作步骤

### 3.1 建立连接

1. 先启动/确认其他 SAMP 工具已就绪（如 Aladin、TOPCAT 已打开）。
2. 确保本机（或局域网内）有一个 SAMP hub 在运行：
   - 若没有，DS9 里 **文件 → SAMP Hub → 启动** 自己起一个。
3. DS9 里 **文件 → SAMP → 连接**：
   - 连接成功后会提示已注册到 hub；此时双方工具互相可见。
4. 用 **文件 → SAMP Hub → 信息** 可查看 hub 和已连接客户端列表。

### 3.2 发送图像给其他工具

1. 在 DS9 中打开/显示一张图像（当前帧）。
2. **文件 → SAMP → 图像 → 广播**。
3. 对端工具（Aladin 等）收到后会加载/显示这张图像。

### 3.3 发送星表给其他工具

1. 在 DS9 中加载一张星表/表格（本地文件或在线星表均可）。
2. **文件 → SAMP → 表 → 广播**。
3. 对端工具收到表格后可继续自己的分析（如 TOPCAT 画图）。

### 3.4 接收其他工具发来的数据

- 对端发来图像 URL → DS9 自动联网下载并加载到新帧。
- 对端发来坐标/天区 → DS9 自动跳到该位置。
- 对端发来 VOTable/表格 → DS9 以星表形式叠加。

> 接收是自动的，前提是 DS9 已 **连接** 到同一 hub。

### 3.5 断开

- 用完后 **文件 → SAMP → 断开连接**；若 hub 是 DS9 起的，**SAMP Hub → 停止** 一并关掉。

## 4. 配置项

- DS9 的 SAMP 功能**开箱即用**，一般无需配置。
- 命令行可控制 SAMP 行为（供脚本化）：`ds9 -samp no` 可关闭启动时自动 SAMP 连接；`-samp hub` 指定 hub 地址等（详见参考手册 SAMP 一章）。
- 局域网联机时，确认防火墙允许 SAMP 使用的端口（默认走 21000 段，具体以 hub 为准）。

---

## 5. 常见问题与提示

| 问题 | 处理办法 |
|---|---|
| 点连接没反应 | 先确认有 hub 在跑（没有就先 **SAMP Hub → 启动**）；对端工具是否已连接同一 hub |
| 对端看不到 DS9 | 双方必须连到**同一个 hub**；检查 hub 信息里的客户端列表 |
| 广播后对方没收到 | 确认连接状态正常后再发；图像以 URL 传递时对方机器要能访问该 URL（局域网需可达） |
| 防火墙拦截 | 放行 SAMP 通信端口（或整个局域网段） |
| 不想每次启动都连 SAMP | 命令行加 `-samp no` 启动，或首选项里关闭自动连接 |

---

*提示：SAMP 的价值在"联动"——DS9 负责看图/选源，Aladin 负责多波段查询，TOPCAT 负责表格分析；数据在工具间流转，联网的部分由各工具自己完成。*
