# 功能四：名称解析（Name Resolution，NRES）

> 一句话定位：输入**天体名称**（如 `M31`、`Crab`、`NGC 224`），DS9 联网把它**解析成坐标**并定位到该天区。
> 适用版本：SAOImageDS9 8.8（汉化版）。本文所有菜单位置均为**汉化后的中文界面**。

---

## 1. 这个功能是做什么的

很多天文对象你用惯了名字（猎户座星云、蟹状星云、某星系），但图像显示需要坐标。名称解析功能会调用**在线名称解析服务器**（默认是 CDS 的 **SIMBAD**），把名称翻译成 RA/Dec 坐标，然后让 DS9 的视图/十字丝跳转到该位置。

典型场景：

- 只记得天体名，不知道坐标。
- 打开一张大视场图像，想快速定位到某个著名天体。
- 用名字把多张图对齐到同一目标。

---

## 2. 界面入口（怎么从菜单调出来）

**路径：菜单栏 → 分析 → 名称解析**

操作顺序：

1. 点击菜单栏 **分析**（Analysis）。
2. 在分析菜单**靠上的位置**（"像素表"下面）找到 **名称解析**（Name Resolution）。
3. 点击它，弹出"名称解析"对话框。

---

## 3. 详细操作步骤

1. 打开 **分析 → 名称解析**，弹出名称解析对话框。
2. 在 **名称** 输入框里填天体名，例如：

   ```
   M31
   ```

   也可以带分辨率更高的名字，如 `NGC 224`、`Crab Nebula`、`3C 273`。

3. 确认**服务器**下拉框（默认 `SIMBAD（CDS）`；下拉里通常还有 NED 等其他服务器可选）。
4. 点击 **应用**（Apply）按钮：

   - DS9 联网向服务器查询该名称；
   - 解析成功后，DS9 会**移动视场/十字丝**到解析出的坐标。

5. 可选操作：

   - **定位（Pan）** —— 只把视场中心移到目标，不放置十字丝。
   - **十字丝（Crosshair）** —— 把十字丝放在目标上（视场不一定移动）。

---

## 4. 配置项

**编辑 → 首选项 → 名称解析（NRES）面板**：

- **服务器**：切换/添加名称解析服务器（默认 `SIMBAD（CDS）`；可加 NED 等）。
- 设置解析后的默认行为（是否移动视场、是否放十字丝等）。

---

## 5. 常见问题与提示

| 问题 | 处理办法 |
|---|---|
| 提示解析失败 | 检查外网连通；确认服务器下拉里选的服务可用（SIMBAD 不可用时换 NED） |
| 名字拼写不确定 | 输入常见名称即可（M31、Crab）；SIMBAD 对别名支持较好 |
| 解析成功但没看到目标 | 图像显示范围可能太小，用 **缩放 → 适配图像**（Zoom → To Fit）或放大后再看 |
| 局域网受限 | 与其余联网功能一致，先配好 **首选项 → HTTP** 代理 |
| 解析后十字丝位置偏 | 确认图像有正确 WCS（打开带 WCS 的 FITS）；无 WCS 图像无法按天区定位 |

---

*提示：名称解析只是"名称→坐标"，图像本身还需要有正确的 WCS 才能把坐标对应到像素位置；对没有 WCS 的裸图，解析结果无法用于定位。*
