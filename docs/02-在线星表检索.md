# 功能二：在线星表检索（Catalogs）

> 一句话定位：按你当前的天区，从 **VizieR（CDS，法国斯特拉斯堡）** 和 **SDSS（斯隆数字巡天）** 等**在线星表服务器**拉取天体目录，并叠加显示在图像上。
> 适用版本：SAOImageDS9 8.8（汉化版）。本文所有菜单位置均为**汉化后的中文界面**。

---

## 1. 这个功能是做什么的

DS9 支持"本地 + 在线"两种星表：

- **本地星表**：直接打开本机的 Starbase（`.rdb`）或 CSV 格式星表文件。
- **在线星表**（本文重点）：通过 VizieR（CDS）和 SDSS 提供的在线服务，按天区（名称或坐标 + 搜索半径）检索目录，把查询结果作为表格/标注叠到图像上，用于对照、标注、交叉匹配。

检索到的天体可以用**星表工具（Catalog Tool）**做排序、筛选、查看详细信息。

---

## 2. 界面入口（怎么从菜单调出来）

**路径：菜单栏 → 分析 → 星表 → 搜索星表**

操作顺序：

1. 点击菜单栏的 **分析**（Analysis）。
2. 鼠标悬停到 **星表**（Catalogs）子菜单（在"图像服务器/档案"的下面）。
3. 点击子菜单第一项 **搜索星表**（Search for Catalogs），会弹出"搜索星表"对话框。

星表子菜单里还有：

- **搜索星表** —— 打开在线星表检索对话框（本文主流程）。
- **全部清除** —— 清掉当前帧上的星表叠加。
- **匹配** —— 对已加载的多张星表做交叉匹配。
- 分隔线以下的列表项 —— 已经配置/加载过的在线星表服务，**点击某项可直接对当前视场查询**（快捷入口）。

---

## 3. 详细操作步骤（完整流程）

### 3.1 打开检索对话框

**分析 → 星表 → 搜索星表**，弹出"搜索星表"窗口。

### 3.2 输入目标与筛选条件

对话框顶部是条件区，主要字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| **名称或编号**（Name or Designation） | 输入天体名称或坐标作为检索中心 | `M31`、`10:47:00 -12:00:00`、`NGC 224` |
| **匹配标题/描述的词语**（Words） | 可选，按关键词过滤目录 | 如 `galaxy` |
| **波长**（Wavelength） | 可选，按波段过滤目录（射电/红外/光学/X 射线等） | 光学、红外… |
| **任务**（Mission） | 可选，按观测任务/卫星过滤 | Chandra、XMM… |
| **天文学**（Astronomy） | 可选，按学科分类过滤 | 恒星、星系… |

> 最少只需要填**名称或坐标**；筛选条件用于缩小目录候选范围。

### 3.3 检索目录列表

点击右下角的 **检索**（Retrieve）按钮。DS9 会**联网联系 CDS（VizieR）服务器**，返回符合条件的星表目录列表（状态栏会显示"正在联系服务器…"）。

### 3.4 选择目录并加载

在返回的目录列表里选中一个（例如 2MASS、USNO-B1、SDSS 某星表），点击 **加载**（Load）。

DS9 随即**以当前视场为中心、按默认半径向该星表服务发起查询**，结果作为表格叠加到图像上（图上出现天体标注，同时打开/更新"星表工具"窗口）。

### 3.5 查看与管理结果

- **分析 → 星表工具**：打开星表工具窗口，可查看字段、排序、筛选、导出。
- **分析 → 星表 → 全部清除**：移除叠加。
- **分析 → 星表 → 匹配**：对多个星表做交叉匹配（用于多波段对照）。

---

## 4. 快捷方式：直接点星表子菜单里的服务项

如果某个在线星表已经出现在 **分析 → 星表** 子菜单的列表里（例如默认配置的常见星表），可以直接点击它，DS9 会立即用当前视场发起查询，跳过"搜索星表"对话框。这是最常用的日常操作。

---

## 5. 命令行 / 脚本方式

星表加载也支持 XPA 命令（供脚本化）：

```
# 从在线星表服务加载（服务名用星表工具里看到的名称）
xpaset -p ds9 catalog load 2MASS
```

（具体服务名以星表子菜单/工具中显示的为准。）

---

## 6. 配置项

**编辑 → 首选项 → 星表（Catalogs）面板**：

- 管理可用的在线星表服务列表（增删服务地址）。
- 设置默认查询参数（如默认搜索半径）。
- 可以在这里把常用星表固定到 **分析 → 星表** 子菜单，实现一键查询。

---

## 7. 常见问题与提示

| 问题 | 处理办法 |
|---|---|
| 点"检索"没反应/报错 | 确认能访问 `cdsarc.u-strasbg.fr`（VizieR）；公司网络需代理时到 **首选项 → HTTP** 配置 |
| 目录列表为空 | 放宽筛选条件（波长/任务/学科留空再试），或确认名称/坐标写法正确 |
| 加载后图上没有标注 | 星表工具窗口里检查是否被筛选隐藏；检查"显示标注"开关 |
| 想用的星表不在列表里 | 到 **首选项 → 星表** 面板添加其 VizieR 目录名，或先用本地 rdb/CSV 文件打开 |
| 结果太多/太卡 | 在星表工具里按亮度/距离排序并设筛选，或缩小搜索半径 |

---

*提示：DS9 支持的服务以 VizieR（CDS）与 SDSS 为主；本地星表文件（rdb/CSV）始终可用，不依赖网络。*
