# 功能一：URL 加载远程 FITS 图像

> 一句话定位：把网络上的 FITS 文件（图像或表格）**直接拉进 DS9 显示**，不用先手动下载到本地。
> 适用版本：SAOImageDS9 8.8（汉化版）。本文所有菜单位置均为**汉化后的中文界面**。

---

## 1. 这个功能是做什么的

DS9 支持直接从 HTTP / HTTPS 网址加载 FITS 数据。只要你能给出一个指向 `.fits` 文件（或 FITS 服务的 URL）的完整地址，DS9 就会联网把数据取回来，显示在当前帧里，和打开本地文件完全一样。

典型场景：

- 从科研机构、镜像站直接打开在线 FITS 文件（例如 `http://foo.bar.edu/foo.fits`）。
- 打开带扩展名的 FITS（如 `foo.fits[1]`、`foo.fits[BCKGRD]`）。
- 打开事件表（Event Table）并直接分箱显示。

---

## 2. 界面入口（怎么从菜单调出来）

**路径：菜单栏 → 文件 → 打开 → URL**

操作顺序：

1. 点击菜单栏的 **文件**（File）。
2. 鼠标悬停到 **打开**（Open）子菜单。
3. 在打开子菜单的**最底部**找到 **URL** 一项，点击它。

（打开子菜单里还有很多其他项，如 FITS、Mosaic、像素掩模等，**URL 在最下面**，别找错。）

> 补充：文件主菜单（不展开"打开"时）里也能直接看到 **URL** 菜单项，点击效果相同。

---

## 3. 详细操作步骤

1. 点击 **文件 → 打开 → URL**。
2. 在弹出的输入框里填写完整的网络地址，例如：

   ```
   http://foo.bar.edu/foo.fits
   ```

   也可以带 FITS 扩展名和分箱参数：

   ```
   http://foo.bar.edu/foo.fits[2][bin=rawx,rawy]
   ```

3. 确认后，DS9 会自动联网下载并把图像加载到当前帧。
4. 窗口状态栏/信息栏会显示加载状态；图像出来后即可正常缩放、标注、保存。

---

## 4. 命令行方式（不用界面）

DS9 在启动时直接传 URL 参数：

```
ds9 -url http://foo.bar.edu/foo.fits
```

等价于打开文件后加载 URL：

```
ds9 http://foo.bar.edu/foo.fits
```

运行中的 DS9 也可以用 XPA 命令推送：

```
xpaset -p ds9 url http://foo.bar.edu/foo.fits
```

SAMP 场景下，其他天文软件发来图像 URL 时 DS9 也会自动加载（前提：已通过 **文件 → SAMP → 连接** 建立连接）。

---

## 5. 配置项

- 本功能**无需专门配置**，只要能访问外网即可。
- 如果所在网络要求使用 HTTP 代理，请在 **编辑 → 首选项 → HTTP** 面板里配置代理服务器地址，DS9 的 URL 下载会走该代理。

---

## 6. 常见问题与提示

| 问题 | 处理办法 |
|---|---|
| 一直转圈/加载失败 | 先确认地址在浏览器里能直接打开；再检查防火墙、代理设置 |
| URL 里有 `&`、`?`、空格等特殊字符 | 需要按 URL 编码规则转义（如空格写 `%20`），否则可能被解析错 |
| 打不开带扩展名的文件 | 扩展名写法与本地一致：`url[ext]`，注意方括号在命令行里要加引号：`ds9 'http://...fits[1]'` |
| 下载大文件很慢 | DS9 是"先下载后加载"，大文件等待时间取决于网络带宽 |
| 想临时看看地址指向的内容 | 先用 **分析 → 网页浏览器** 打开该 URL 确认内容再加载 |

---

*备注：DS9 会先把远程文件下载到临时目录再加载，因此磁盘上不需要你手动保存这份 FITS；需要留档时记得用 **文件 → 保存** 另存到本地。*
