Printing 打印（Printing）

DS9 provides strong Postscript printing support. This is not a screen capture method, but a full level 1/2/3 postscript driver. The postscript images generated are as detailed and accurate as possible, given the resolution of the data, and the printing resolution.

DS9 提供强大的 Postscript 打印支持。这不是屏幕截图方式，而是一个完整的 Level 1/2/3 Postscript 驱动程序。所生成的 Postscript 图像会在数据分辨率和打印分辨率允许的范围内尽可能详尽和准确。

Postscript Level

Postscript 级别（Postscript Level）

Level 1-- The postscript generated consists of a color lookup table and image data, encoded in ASCIIHEX. All line graphics and text are postscript elements.

Level 1——生成的 Postscript 由颜色查找表和图像数据组成，以 ASCIIHEX 编码。所有线图形和文字都是 Postscript 元素。

Level 2-- The postscript generated consists of a color lookup table and image data, compressed with RLE, and encoded in ASCIIHEX85. All line graphics and text are postscript elements.

Level 2——生成的 Postscript 由颜色查找表和图像数据组成，用 RLE 压缩，并以 ASCIIHEX85 编码。所有线图形和文字都是 Postscript 元素。

Level 3-- The postscript generated consists of a color lookup table and image data, compressed with GZIP. All line graphics and text are postscript elements.

Level 3——生成的 Postscript 由颜色查找表和图像数据组成，用 GZIP 压缩。所有线图形和文字都是 Postscript 元素。

Resolution

分辨率（Resolution）

Unlike graphic elements, image data must be sampled when encoded into postscript. The specified resolution parameter is in "pixels per inch" and is independent of the current screen resolution. A value of 96 maps to the current screen resolution. Any value over 96 will over sample the image, while any value under 96 will under sample. For high resolution printers and posters, the higher resolution sampling, the better. However, keep in mind the size of the postscript file grows with the square of the increase in resolution.

与图形元素不同，图像数据在编码为 Postscript 时必须经过采样。指定的分辨率参数以“像素/英寸”为单位，与当前屏幕分辨率无关。取值 96 对应当前屏幕分辨率；大于 96 会对图像过采样，小于 96 则欠采样。对于高分辨率打印机和海报，采样分辨率越高越好。但请记住：Postscript 文件的大小随分辨率增幅的平方而增长。
