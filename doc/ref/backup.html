Backup and Restore 备份与恢复

DS9 now supports Backup and Restore. When a backup is invoked, DS9 will save in a backup save set all files needed to restore DS9 to that state, including geometry, data files, colormaps, catalogs, contours, and regions.

DS9 现在支持备份与恢复（Backup and Restore）功能。执行备份时，DS9 会将恢复至该状态所需的全部文件（包括几何信息、数据文件、颜色映射、星表、等高线和区域）保存到备份保存集（backup save set）中。

If the user specifies -title Foo, DS9 will use .Foo.bck for automatic backups.

如果用户指定了 -title Foo，DS9 将使用 .Foo.bck 进行自动备份。

Backup Save Set

备份保存集

A backup save set consists of a text file, called a backup script, and an optional directory, which will contain auxiliary data files needed to restore DS9 to a previous state. The backup file and the auxiliary directory may be moved across file systems, or even platforms, but must remain together in the same directory.

备份保存集由一个称为备份脚本（backup script）的文本文件和一个可选目录组成，该目录包含恢复 DS9 至先前状态所需的辅助数据文件。备份文件和辅助目录可以跨文件系统甚至跨平台移动，但必须一起保留在同一目录中。

Image data files

图像数据文件

By default, all data image files are saved within the backup save set. However, the user has the option, via the Preferences, to save only an absolute pathname to the data file, and not the data file itself. This option will dramatically reduce the size of a backup save set, but will restrict the usage to a particular file system and platform.

默认情况下，所有数据图像文件都会保存到备份保存集中。但用户可以通过“首选项”（Preferences）选择只保存数据文件的绝对路径名，而不保存数据文件本身。此选项将大幅减小备份保存集的大小，但会将用途限制在特定的文件系统和平台上。

Image files that have been loaded into DS9 via XPA, SAMP, or from a URL will always be saved into the save set.

通过 XPA、SAMP 或从 URL 加载到 DS9 的图像文件将始终保存到保存集中。

Caveats

注意事项

There are several caveats in the usage of Backup and Restore. In particular:

使用备份与恢复功能时有几点注意事项，特别是：

Currently, there is no support for masks.
External Analysis menus will not be saved.
Plot Tool windows will not be saved.
IIS frames (IRAF) will not be saved.
SAMP and XPA sessions will not be saved.

目前不支持掩模（masks）；外部分析（External Analysis）菜单不会保存；绘图工具（Plot Tool）窗口不会保存；IIS 帧（IRAF）不会保存；SAMP 和 XPA 会话不会保存。

And finally, if the image data has been loaded into DS9 via XPA, SAMP, or from a URL, the following complex load operations are not supported:

最后，如果图像数据已通过 XPA、SAMP 或 URL 加载到 DS9，则以下复杂的加载操作不受支持：

Open Mosaic IRAF Image
Open Mosaic IRAF Segment Open Mosaic WCS Image
Open Mosaic WCS Segment Open Mosaic WFPC2 Open RGB Fits Image Open RGB Fits Cube Open RGB Array Open Multi Ext Data Cube Open Multi Ext Multiple Frames

打开 IRAF 拼接图像、打开 IRAF 拼接分段、打开 WCS 拼接图像、打开 WCS 拼接分段、打开 WFPC2 拼接、打开 RGB FITS 图像、打开 RGB FITS 立方体、打开 RGB 数组、打开多扩展数据立方体、打开多扩展多帧。
