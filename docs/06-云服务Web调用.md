# 功能六：云服务（Cloud Computing，$geturl / $url）

> 一句话定位：DS9 的"分析命令"支持 `$geturl()` 与 `$url()` 宏，让你**直接调用 HTTP(S) Web 服务**：云端算完的结果以文本/图像/FITS 返回，DS9 负责接收并显示。
> 适用版本：SAOImageDS9 8.8（汉化版）。本文所有菜单位置均为**汉化后的中文界面**。

---

## 1. 这个功能是做什么的

DS9 内置的"分析命令"机制可以把当前帧的上下文（文件名、坐标、区域等）传给外部程序执行。其中 `$geturl()` / `$url()` 这两个宏专门用来**调用任意 HTTP(S) GET 接口**，把云端/局域网里的 Web 服务当成"处理流水线"：

- `$geturl(...)` → 接口返回的**文本**显示在文本窗口。
- `$url(...) | $image` → 接口返回的**图像/FITS** 加载到帧。

典型场景：

- 自建 Flask/Python 等 Web 服务，把 DS9 发来的区域/坐标在云端处理，返回结果。
- 调用团队内部的图像处理接口，直接得到成品图。
- 对接第三方的 HTTP 数据服务。

> 说明：这是面向**开发者/进阶用户**的功能。需要你（或团队）先有一个能接受 GET 请求的 Web 服务端点，DS9 侧只是"调用 + 显示"。

---

## 2. 原理速览：分析命令文件

DS9 的云功能不是菜单里现成的一项，而是**通过分析命令文件**（`ds9.ans` / `ds9.analysis`）注册到 **分析** 菜单。文件格式：

```
# 注释：菜单里显示的名字
$geturl(http://127.0.0.1:5000/) | $text
menu
```

每 3 行为一条命令：

| 行 | 内容 |
|---|---|
| 第 1 行 | 命令内容（可含 `$geturl()`、`$url()`、`$param()` 等宏） |
| 第 2 行 | `menu`（出现在分析菜单）/ `button`（按钮栏）/ `bind`（绑定事件） |
| 第 3 行 | 命令名（菜单里显示的名称） |

关键宏：

- `$geturl(url)` —— 调用 URL，把返回的**文本**交给后续管道（配合 `| $text` 显示）。
- `$url(url)` —— 调用 URL，把返回的**图像数据**交给后续管道（配合 `| $image` / `| $image(new)` 加载到帧）。
- `$param(名字)` —— 把用户在弹窗里输入的参数拼进 URL。
- `$filename`、`$xpa` 等 —— 当前帧信息宏（文件名、XPA 地址等）。

## 3. 界面入口（怎么从菜单调出来）

### 3.1 加载分析命令文件

**路径：菜单栏 → 分析 → 加载分析命令**

操作顺序：

1. 点击菜单栏 **分析**（Analysis）。
2. 在分析菜单**底部**找到 **加载分析命令**（Load Analysis Commands）。
3. 选择你的 `.ans` / `.analysis` 文件 → 加载成功。
4. 文件里定义的命令随即出现在 **分析** 菜单中（按文件名分组）。

之后每次要执行云服务：

- 直接点击 **分析 →（你定义的命令名）** → 弹出参数输入（如有 `$param()`）→ 确认 → DS9 调用云端接口并显示结果。

### 3.2 相关菜单项

- **分析 → 清除分析命令**：卸载全部自定义命令。
- **编辑 → 首选项 → 分析** 面板：设置启动时自动加载的分析文件（如 `ds9.ans` 放当前目录或 `$HOME` 会自动加载）。

## 4. 最小可跑示例

### 4.1 云端服务（以 Flask 为例，运行在 127.0.0.1:5000）

```python
from flask import Flask, request
app = Flask(__name__)

@app.route('/')
def hello():
    return "Hello from DS9 cloud!"

@app.route('/simple_parameter/')
def simple():
    text = request.args.get('text', '')
    return "你输入了：" + text

if __name__ == '__main__':
    app.run(port=5000)
```

### 4.2 DS9 分析文件（cloud.ans）

```
# 调用本机 Flask 服务，返回文本
$geturl(http://127.0.0.1:5000/) | $text
menu
云端问候

# 带参数调用：弹窗收集 text
$param(请输入文本); $geturl(http://127.0.0.1:5000/simple_parameter/?text=$param(text)) | $text
menu
云端带参查询
```

### 4.3 使用步骤

1. 启动 Flask 服务。
2. DS9 里 **分析 → 加载分析命令** → 选 `cloud.ans`。
3. **分析 → 云端问候** → 文本窗口显示 `Hello from DS9 cloud!`。
4. **分析 → 云端带参查询** → 输入文本 → 显示"你输入了：xxx"。

### 4.4 返回图像（示例）

```
$url(http://127.0.0.1:5000/get_img) | $image(new)
menu
云端取图
```

云端 `/get_img` 返回一张图像（FITS/PNG 等，按 `multipart/mixed` 容器封装的 FITS 亦可），DS9 自动加载到新帧。

## 5. 注意事项（重要）

| 事项 | 说明 |
|---|---|
| **只支持 GET** | DS9 的 `$geturl`/`$url` 只发 GET 请求；**不支持 POST、文件上传** |
| URL 编码 | URL 里的 `?`、`&`、空格等特殊字符要按 GET 规则编码（空格 `%20` 等） |
| 参数传递 | 需要用户输入时用 `$param(名字)`，DS9 会先弹窗收集 |
| 网络可达性 | 云端服务地址必须能从运行 DS9 的机器访问（本地 127.0.0.1 只对本机有效） |
| 结果容器 | 返回 FITS 图像时，多部分/多对象要用 `multipart/mixed` 容器并设 `Content-Transfer-Encoding: base64` |

---

## 6. 常见问题与提示

| 问题 | 处理办法 |
|---|---|
| 点了命令没反应 | 先用浏览器手动打开那个 URL 验证服务在跑；确认端口/路径正确 |
| 参数没传过去 | 检查 `$param()` 拼写与 URL 拼接；参数值含特殊字符时注意编码 |
| 返回文本乱码 | 服务端确认返回编码为 UTF-8 |
| 图像加载失败 | 确认返回类型与容器格式（见第 5 节）；先在浏览器里看 URL 是否直接返回图像 |
| 不想每次加载文件 | 把分析文件放进 `$HOME` 或当前目录（自动加载），或在 **首选项 → 分析** 里固定 |

---

*提示：云服务是 DS9 联网能力里最"自由"的一项——接口怎么设计、返回什么，完全由你的 Web 服务决定；DS9 只负责"按 GET 调用 → 收结果 → 显示"。*
