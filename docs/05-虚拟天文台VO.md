# 功能五：虚拟天文台（Virtual Observatory，VO）

> 一句话定位：DS9 内置一个**虚拟天文台服务器列表**，点一下就连到对应 VO 站点（如 NASA/IPAC、ESO 等），在其网页上检索数据；服务器也可以反过来取走你本地的图像做分析。
> 适用版本：SAOImageDS9 8.8（汉化版）。本文所有菜单位置均为**汉化后的中文界面**。

---

## 1. 这个功能是做什么的

虚拟天文台把分散在各机构的天文数据/服务统一成"在线站点"。DS9 的 VO 功能：

- 在 VO 列表里点一个服务器 → DS9 尝试**直接连接**该站点 → 连接成功后在其网页里检索/浏览数据。
- 站点通常支持**取走你本地的图像**（你分析自己的数据，服务器帮你跑），也支持把图像结果发回 DS9。
- 内嵌网页浏览器与独立网页浏览器都可以配合使用。

典型场景：

- 到 VO 站点按天区检索档案图像/光谱。
- 把 DS9 里正在看的图像交给 VO 站点做在线分析。
- 在多个 VO 站点之间对比服务。

---

## 2. 界面入口（怎么从菜单调出来）

**路径：菜单栏 → 分析 → 虚拟天文台**

操作顺序：

1. 点击菜单栏 **分析**（Analysis）。
2. 在分析菜单**中部**（"绘图工具"之后）找到 **虚拟天文台**（Virtual Observatory）。
3. 点击它，弹出"虚拟天文台"对话框，里面是服务器列表。

> 另有一个独立入口：**分析 → 网页浏览器**（Web Browser），可以单独打开内嵌浏览器浏览任意网址（VO 检索常配合它使用）。

---

## 3. 详细操作步骤

1. 打开 **分析 → 虚拟天文台**。
2. 在服务器列表中点击一个 VO 服务器：
   - 列表项左侧的**状态方块**会先变**黄色**（正在连接），连接成功后变**绿色**。
3. 连接成功后：
   - 若启用了内嵌 Web 显示，DS9 会在内置浏览器里打开该 VO 站点页面，你在页面上按站点自己的检索界面操作（填天区、选数据集等）。
   - 也可以配合 **分析 → 网页浏览器** 用内置浏览器浏览。
4. 需要服务器处理本地数据时，按站点页面提示操作（服务器会从 DS9 侧获取当前图像）。
5. 检索/分析结果按站点支持的方式回传到 DS9（常见：返回图像 URL → 自动加载到新帧）。

---

## 4. 直连 vs Web 代理（重要）

| 方式 | 适用场景 | 限制 |
|---|---|---|
| **直连** | 本机网络允许直接访问外部 | 快、灵活；可用外部浏览器；可分析本地数据 |
| **Web 代理** | 防火墙只允许走代理（如 SOCKS） | 慢；**必须用内嵌浏览器**；**不能分析本地数据**；区域数量有限制 |

如何配置代理：

- 在 VO 对话框里点击 **配置 Web 代理（Configure Web Proxy）** 按钮，填入代理地址/端口（管理员会告诉你）；或
- 在 **编辑 → 首选项 → HTTP** 面板统一配置。

---

## 5. 配置项

**编辑 → 首选项 → 虚拟天文台（VO）面板**：

- 管理 VO 服务器列表（增删站点）。
- 设置是否启用内嵌 Web 显示、默认浏览器行为。

---

## 6. 常见问题与提示

| 问题 | 处理办法 |
|---|---|
| 状态方块一直黄色、最终报错 | 直连失败：确认外网可达；受限网络则改走 Web 代理（见第 4 节） |
| 连上了但页面空白 | 检查是否启用了内嵌 Web 显示；尝试 **分析 → 网页浏览器** 手动打开 |
| 走代理后功能变少 | 属正常限制（不能分析本地数据、传输慢），见第 4 节表格 |
| 想用外部浏览器看图 | 仅直连模式支持；代理模式必须用内嵌浏览器 |
| 站点列表不够用 | 到 **首选项 → VO** 面板添加站点 |

---

*提示：VO 连接是否成功，最直观的信号就是列表左侧方块**黄→绿**。变绿后即可正常交互。*
