Frame Commands (Developer Reference)帧命令（开发者参考）

Every DS9 frame is itself a Tcl canvas item with its own command name (e.g. Frame1, Frame2, ...; $::current(frame) always holds the name of the currently selected one — see The current Array). This page documents every command that name accepts — the frame-level grammar implemented by a bison/flex parser in tksao/frame/parser.Y and tksao/frame/lex.L in the DS9 source tree. It is one level below the Tcl library in ds9/library/*.tcl: most menu actions and XPA access points are themselves thin wrappers that eventually call one of these frame commands.

DS9 的每一帧本身就是一个 Tcl 画布（canvas）条目，拥有自己的命令名（例如 Frame1、Frame2……；$::current(frame) 始终保存当前所选帧的命令名——参见 当前 Array）。本页记录该命令名所能接受的全部命令，即由 DS9 源码树中 tksao/frame/parser.Y 与 tksao/frame/lex.L 的 bison/flex 解析器实现的帧级语法。它位于 ds9/library/*.tcl Tcl 库之下一层：大多数菜单动作与 XPA 访问点本身只是薄封装，最终都会调用这里的某个帧命令。

This is developer-level documentation aimed at scripting DS9 from the -tcl command line option, from a ~/.ds9.ini (or ~/ds9.ini) startup file (any Tcl file of that name in your home directory is automatically sourced once DS9 has finished starting up — see SourceInitFileDir in ds9/library/util.tcl), or from the tcl XPA access point. A typical invocation looks like:

这是面向开发者的文档，用于通过 -tcl 命令行选项、~/.ds9.ini（或 ~/ds9.ini）启动文件（主目录下任何该名称的 Tcl 文件都会在 DS9 启动完成后自动被 source——见 ds9/library/util.tcl 中的 SourceInitFileDir），或通过 tcl XPA 访问点来脚本化驱动 DS9。典型调用如下：

set d [$::current(frame) get zoom]
$::current(frame) pan 100 100
$::current(frame) marker create circle 256 256 20

上面三行分别演示：读取当前帧的缩放系数、把视图平移到 (100,100)、在 (256,256) 处创建一个半径 20 的圆形标记。

All keywords are matched case-insensitively by the lexer (%option caseless), but are written lowercase by convention, which this page follows. get ... and has ... forms compute a value and return it as the result of the Tcl command — use set x [$::current(frame) get ...] to capture it; every other command performs an action on the frame and its Tcl return value is not meaningful. A handful of commands accept no arguments at all (e.g. center, show) and simply perform their action.

所有关键字都由词法分析器（%option caseless）按大小写不敏感方式匹配，但按惯例一律小写书写，本页也遵循此惯例。get ... 与 has ... 形式会计算一个值并作为 Tcl 命令的结果返回——用 set x [$::current(frame) get ...] 来捕获它；其余所有命令都对帧执行某个动作，其 Tcl 返回值没有意义。少数命令完全不接受参数（例如 center、show），直接执行其动作即可。

Numbers written <value> below accept either an integer or a real number. Where a command's arguments depend on a coordinate system or sky frame given earlier in the same command, see Common Parameter Types for the full set of choices — that section is referenced throughout instead of being repeated for every command.

下文写作 <value> 的数字既可以是整数也可以是实数。当某命令的参数依赖于同一命令中先前给出的坐标系或天球框架时，完整可选集合见 公共参数类型——全页都引用该节，而不在每条命令处重复。

Common Parameter Types公共参数类型

These placeholders are used throughout this page instead of being spelled out in every command's syntax.

下列占位符在全页统一使用，而不在每条命令的语法中逐一展开。

<value>
A plain number, e.g. 10 or -3.5.

一个普通数字，例如 10 或 -3.5。

<yesno>
yes (also y, on, true, or a non-zero integer) or no (also n, off, false, or 0).

yes（也可写作 y、on、true 或非零整数）或 no（也可写作 n、off、false 或 0）。

<angle>
A plain number in degrees, or a number suffixed with d for degrees or r for radians (e.g. 90, 90d, 1.5708r).

以度为单位的普通数字，或带 d（度）/r（弧度）后缀的数字（例如 90、90d、1.5708r）。

<coordSystem>
image | physical | amplifier | detector | <wcsSystem>

坐标系：image（图像像素）| physical（物理坐标）| amplifier（放大器坐标）| detector（探测器坐标）| 或 <wcsSystem> 世界坐标系统。

<wcsSystem>
wcs (the primary/current WCS) or one of the 26 alternate WCS systems wcsa through wcsz that a FITS header may define (WCSAXES-style alternate WCS letters), or wcs0 (reset/none). Used for coordSystem above, and directly by load ... mosaic, wcs, and match.

wcs（主/当前 WCS），或 FITS 头可能定义的 26 个备用 WCS 系统之一（wcsa 到 wcsz，即 WCSAXES 风格的备用字母），或 wcs0（重置/无）。用于上面的 coordSystem，也被 load ... mosaic、wcs、match 直接使用。

<internalSystem>
canvas (screen pixels of the Tk canvas) or panner (screen pixels of the panner widget). Used where a command needs raw widget pixel coordinates rather than an image-based coordSystem.

canvas（Tk 画布的屏幕像素）或 panner（全景导航器控件的屏幕像素）。用于需要原始控件像素坐标、而非基于图像的 coordSystem 的场合。

<skyFrame>
fk4 (or b1950) | fk5 (or j2000) | icrs (default) | galactic | ecliptic. Only meaningful when the preceding coordSystem is a WCS system; ignored otherwise. If omitted where the grammar allows it, defaults to icrs.

天球框架：fk4（或 b1950）| fk5（或 j2000）| icrs（默认）| galactic（银道）| ecliptic（黄道）。仅在前面的 coordSystem 是 WCS 系统时才有意义，否则被忽略；语法允许省略时默认为 icrs。

<skyFormat>
degrees (default) | sexagesimal — how a returned sky coordinate is formatted.

degrees（十进制度，默认）| sexagesimal（六十进制）——返回的天球坐标的格式。

<skyDist>
degrees (default) | arcmin | arcsec — the unit of a returned or supplied angular size/distance.

degrees（度，默认）| arcmin（角分）| arcsec（角秒）——返回或输入的角距离/角大小的单位。

<coord>
A coordinate pair appropriate to the coordSystem/skyFrame just given: two plain numbers (<x> <y>) for image/physical/amplifier/detector/wcs systems, or two sexagesimal strings DD:MM:SS.s DD:MM:SS.s, or an HMS/DMS pair HHhMMmSS.ss DDdMMmSS.ss, for a sky frame.

与刚给出的 coordSystem/skyFrame 相匹配的一对坐标：对 image/physical/amplifier/detector/wcs 系统为两个普通数字（<x> <y>）；对天球框架则为两个六十进制字符串 DD:MM:SS.s DD:MM:SS.s，或一对 HMS/DMS 写法 HHhMMmSS.ss DDdMMmSS.ss。

<endian>
native (default) | big (or bigendian) | little (or littleendian).

字节序：native（本机，默认）| big（或 bigendian，大端）| little（或 littleendian，小端）。

<fileNameType>
root base (default, e.g. foo) | root (e.g. foo.fits) | full base (e.g. foo with directory stripped only) | full (complete path).

文件名形式：root base（默认，如 foo，去目录去扩展名）| root（如 foo.fits，去目录）| full base（如 foo，仅去掉目录）| full（完整路径）。

<layerType>
image (default) | mask — whether data being loaded becomes the frame's image data or a pixel mask layer.

image（默认）| mask——载入的数据成为帧的图像数据，还是一个像素掩膜层。

<shmType>
shmid (default, a System V shared memory id) | key (a System V shared memory key). Used by the shared/sshared forms of load/save.

shmid（默认，System V 共享内存 id）| key（System V 共享内存键）。供 load/save 的 shared/sshared 形式使用。

<cutMethod>
average (default) | sum | median.

剖面取值方式：average（平均，默认）| sum（求和）| median（中值）。

<scaleType>
linear | log | pow | sqrt | squared | asinh | sinh | histequ.

灰度拉伸类型：linear（线性）| log（对数）| pow（幂）| sqrt（平方根）| squared（平方）| asinh（反双曲正弦）| sinh（双曲正弦）| histequ（直方图均衡）。

<minmaxMode>
auto | scan | sample | datamin | irafmin.

最小值/最大值取值模式：auto（自动）| scan（扫描全图）| sample（采样）| datamin（数据最小）| irafmin（IRAF zscale 风格）。

<maskType>
zero | nonzero (default) | nan | nonnan | range.

掩膜类型：zero（零值）| nonzero（非零，默认）| nan（NaN）| nonnan（非 NaN）| range（范围）。

<maskBlend>
source (default) | multiply | screen | overlay | darken | lighten | color-dodge | color-burn | hard-light | soft-light | difference | exclusion | hue | saturation | color | luminosity. Also used by layer for image-layer blending.

混合模式：source（正常，默认）| multiply（正片叠底）| screen（滤色）| overlay（叠加）| darken（变暗）| lighten（变亮）| color-dodge（颜色减淡）| color-burn（颜色加深）| hard-light（强光）| soft-light（柔光）| difference（差值）| exclusion（排除）| hue（色相）| saturation（饱和度）| color（颜色）| luminosity（明度）。layer 进行图像层混合时也使用此参数。

<pointShape>
circle (default) | box | diamond | cross | x | arrow | boxcircle.

点形状：circle（圆点，默认）| box（方点）| diamond（菱形）| cross（十字）| x（叉）| arrow（箭头）| boxcircle（圆框）。

<analysisTask>
panda (also cpanda) | histogram | plot2d | plot3d | radial | stats.

分析任务：panda（panda 形状，亦作 cpanda）| histogram（直方图）| plot2d（二维图）| plot3d（三维图）| radial（径向分布）| stats（统计）。

<analysisMethod>
average (default) | sum | median.

分析统计方式：average（平均，默认）| sum（求和）| median（中值）。

<markerCallBack>
One of: select, unselect, highlite, unhighlite, begin move, move, end move, begin edit, edit, end edit, begin rotate, rotate, end rotate, delete, text, color, width, property, font, key, update — the marker lifecycle event a callback clause fires on. Used by marker's callback= property and callback/delete callback verbs.

标记生命周期事件之一：select（选中）、unselect（取消选中）、highlite（高亮）、unhighlite（取消高亮）、begin move/move/end move（移动开始/拖动中/结束）、begin edit/edit/end edit（编辑）、begin rotate/rotate/end rotate（旋转）、delete（删除）、text（文本）、color（颜色）、width（线宽）、property（属性）、font（字体）、key（按键）、update（更新）——即 callback 子句所挂载的事件。供 marker 的 callback= 属性及 callback/delete callback 动词使用。

<markerProperty>
none | select | highlite | dash | fixed | edit | move | rotate | delete | include | source | fill — one of a marker's boolean behavior flags, set with property <markerProperty> <yesno>.

标记布尔行为标志之一：none（无）| select（可选）| highlite（可高亮）| dash（虚线）| fixed（固定）| edit（可编辑）| move（可移动）| rotate（可旋转）| delete（可删除）| include（包含）| source（源标记）| fill（填充），用 property <markerProperty> <yesno> 设置。

<pscolorspace>
bw | gray | rgb | cmyk. Used by postscript.

PostScript 颜色空间：bw（黑白）| gray（灰度）| rgb | cmyk。供 postscript 使用。

<gridType>
analysis | publication. Used by grid.

网格类型：analysis（分析网格）| publication（出版网格）。供 grid 使用。

<contourMethod>
smooth | block. Used by contour.

等高线生成方式：smooth（平滑）| block（分块）。供 contour 使用。

<contourClipMode>
minmax | zscale | zmax | user. Used by contour (a subset of clip modes, without auto/sample/datamin/irafmin).

等高线裁剪模式：minmax | zscale | zmax | user。供 contour 使用（是 裁剪模式 的子集，不含 auto/sample/datamin/irafmin）。

<contourClipScope>
global | local. Used by contour and clip scope.

裁剪范围：global（全局）| local（局部）。供 contour 及 clip scope 使用。

<renderMethod>
mip | aip | fip. Used by threed.

三维渲染方法：mip（最大强度投影）| aip（平均强度投影）| fip（首次强度投影）。供 threed 使用。

<renderBackground>
none | azimuth | elevation. Used by threed.

三维背景：none（无）| azimuth（方位角着色）| elevation（仰角着色）。供 threed 使用。

<smoothFunction>
boxcar | tophat | gaussian | elliptic. Used by smooth.

平滑函数：boxcar（矩形窗）| tophat（顶帽）| gaussian（高斯）| elliptic（椭圆）。供 smooth 使用。

<markerFormat>
ds9 (default) | xml | ciao | saotng | saoimage | pros | xy (raw x/y). The region file dialect for marker load/save/list/command.

区域文件方言：ds9（默认）| xml | ciao | saotng | saoimage | pros | xy（原始 x/y）。供 marker 的 load/save/list/command 使用。

<markerLayer>
An optional word right after marker/region/get marker selecting which layer of markers to operate on: omitted (default), region, user, or pointer all mean the normal user-created region layer; catalog means catalog-overlay markers; footprint means footprint-overlay markers. See marker.

紧跟在 marker/region/get marker 之后的可选层名，指定操作哪一层标记：省略（默认）、region、user、pointer 都指普通的用户创建区域层；catalog 指星表叠加层标记；footprint 指足迹（footprint）叠加层标记。见 marker。

bin分箱（事件表分箱）

Controls binning of FITS bin-table (event list) data: bin factor, bin center, binning columns, buffer size, and the binning function.

控制 FITS 二进制表（事件列表）数据的分箱：分箱系数、分箱中心、分箱列、缓冲区大小以及分箱函数。

Syntax:
bin about center
bin about <x> <y>
bin buffer size <value>
bin cols <xcol> <ycol> <zcol>
bin depth <value>
bin factor <value> [<value>]
bin factor <value> [<value>] about <x> <y>
bin factor to <value> [<value>]
bin factor to <value> [<value>] about <x> <y>
bin filter <string>
bin function average|sum
bin to fit
bin to <fx> <fy> about center <xcol> <ycol> <zcol>
bin to <fx> <fy> about <ax> <ay> <xcol> <ycol> <zcol>
bin to <fx> <fy> <depth> <dx> <dy> about center <xcol> <ycol> <zcol> <tcol>
bin to <fx> <fy> <depth> <dx> <dy> about <ax> <ay> <xcol> <ycol> <zcol> <tcol>
 
Example:
$::current(frame) bin about center
$::current(frame) bin about 512 512
$::current(frame) bin buffer size 1024
$::current(frame) bin cols detx dety time
$::current(frame) bin factor 4
$::current(frame) bin factor 4 2 about 512 512
$::current(frame) bin filter {pha > 5}
$::current(frame) bin function sum
$::current(frame) bin to fit
$::current(frame) bin to 4 4 about center detx dety time

The bin to <fx> <fy> ... forms are a legacy one-shot combination of setting the bin factor, the about-point, and the binning columns (and, in the four-column forms, a bin buffer depth) in a single call; prefer the separate bin factor/bin about/bin cols/bin depth commands above in new scripts.

bin to <fx> <fy> ... 形式是旧式的一次性组合调用，在一条命令里同时设置分箱系数、基准点和分箱列（四列形式还设置分箱缓冲深度）；新脚本请优先使用上面独立的 bin factor/bin about/bin cols/bin depth 命令。
