# 功能七：分析任务与外部命令（Analysis）

> 一句话定位：DS9 可以把"当前帧信息"（文件名、坐标、区域等）**交给外部程序执行**，结果再回到 DS9 显示；其中 `web` 类型的命令直接**打开网页/URL**——这是分析任务里最典型的联网用法。
> 适用版本：SAOImageDS9 8.8（汉化版）。本文所有菜单位置均为**汉化后的中文界面**。

---

## 1. 这个功能是做什么的

DS9 允许用户为每种文件类型定义"分析命令"：点一下菜单，DS9 就把当前帧的相关信息通过**宏**展开传给外部命令，外部命令执行后把结果送回 DS9（文本窗口 / 绘图窗口 / 图像帧）。

命令有四种类型：

| 类型 | 出现位置 | 典型用途 |
|---|---|---|
| `menu` | **分析** 菜单里 | 最常用，点菜单执行 |
| `button` | 按钮栏 | 常驻一个按钮，点按钮执行 |
| `bind` | 绑定快捷键/鼠标事件 | 按快捷键触发 |
| `web` | 分析菜单 | **调用内部网页浏览器打开 URL（联网）** |

> 联网点有两类：① `web` 类型直接开网页；② 外部命令本身是网络程序（如调用某个在线 API 的脚本）——是否联网由命令内容决定，DS9 只负责执行与回显。

---

## 2. 界面入口（怎么从菜单调出来）

### 2.1 加载分析命令

**路径：菜单栏 → 分析 → 加载分析命令**

1. 点击菜单栏 **分析**（Analysis）。
2. 在分析菜单**最底部**找到 **加载分析命令**（Load Analysis Commands）。
3. 选择 `ds9.ans` / `ds9.analysis` 文件（或任意 `.ans` 文件）→ 加载。
4. 加载后，文件里定义的命令按文件名分组出现在 **分析** 菜单中。

### 2.2 其他相关菜单

- **分析 → 清除分析命令** —— 卸载全部命令。
- **分析 → 分析命令日志** —— 勾选后可记录命令执行历史（调试用）。
- **编辑 → 首选项 → 分析** 面板 —— 配置启动时自动加载的分析文件、按钮栏分析按钮。

### 2.3 自动加载

DS9 启动时自动搜索并加载以下文件：

- 当前目录和 `$HOME` 下的 `ds9.ans`、`ds9.analysis`；
- 当前目录、`$HOME/bin`、`/usr/local/bin` 等路径下的 `*.ds9` 分析文件。

所以把常用命令写进 `$HOME\ds9.ans`，以后每次启动分析菜单里都直接可用。

---

## 3. 详细操作步骤（写一个能联网的命令）

### 3.1 分析文件格式（每 3 行一条命令）

```
<命令内容，可含宏>
<类型：menu / button / bind / web>
<菜单/按钮显示的名称>
```

### 3.2 示例 1：web 类型（联网开网页）

```
# 用内部浏览器打开 NASA ADS 文献检索（按当前帧目标）
web
检索当前目标的文献
```

实际命令内容（第 1 行）里可以组合 URL 与宏，例如：

```
http://adsabs.harvard.edu/?q=$target
web
在 ADS 检索当前目标
```

> 说明：`web` 类型命令就是"把这一行当作 URL 用内部浏览器打开"，因此 URL 里可用 `$filename`、`$regions`、`$target` 等宏拼参数。

### 3.3 示例 2：外部命令（联网与否取决于命令本身）

```
# 调用本机脚本处理当前图像（脚本内部可再访问网络）
python C:/tools/ds9_proc.py $filename | $text
menu
运行我的处理脚本
```

### 3.4 执行步骤

1. 写好 `.ans` 文件；
2. **分析 → 加载分析命令** → 选中文件；
3. **分析 →（你定义的命令名）** → 执行；
4. 结果按命令里的管道目标显示：`| $text`（文本窗口）、`| $image`（图像帧）、`| $plot`（绘图窗口）。

---

## 4. 常用宏速查

| 宏 | 含义 |
|---|---|
| `$filename` | 当前帧的文件名 |
| `$imagedata` | 图像数据（按需传给命令） |
| `$regions` | 当前帧的区域列表 |
| `$target` | 目标对象（若已通过名称解析等设置） |
| `$xpa` | 当前 DS9 的 XPA 地址 |
| `$param(名字)` | 弹窗收集的参数 |
| `$geturl()` / `$url()` | 调用 HTTP 接口（详见《功能六：云服务》） |

> 不想被展开的 `$` 用 `$$` 转义。

---

## 5. 配置项

**编辑 → 首选项 → 分析 面板**：

- 菜单项开关（等高线、坐标网格、块、平滑等在分析菜单里的显隐）。
- 按钮栏的分析按钮配置。
- 启动自动加载的分析文件列表。

---

## 6. 常见问题与提示

| 问题 | 处理办法 |
|---|---|
| 加载文件后分析菜单没有新命令 | 检查文件编码/格式（每 3 行一条，类型行必须正确）；看 **分析命令日志** 是否报错 |
| web 命令打不开网页 | 确认第 1 行是完整 URL；特殊字符按 URL 编码；检查网络 |
| 命令执行了但没结果 | 确认命令里写了管道目标（`\| $text` / `\| $image`）；外部程序 stdout 是否正确 |
| 想取消某条命令 | **分析 → 清除分析命令** 全部卸载，或编辑文件后重新加载 |
| 命令里有中文乱码 | 分析文件存成 UTF-8（DS9 9.x 默认按 UTF-8 读） |

---

*提示：分析任务是把 DS9 与外部世界连接起来的通用"胶水"：本地脚本、Web 服务、网页检索都能接进来。联网能力来自命令本身，DS9 只负责传参数、执行、收结果。*
